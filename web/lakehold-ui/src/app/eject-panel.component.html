An eject bundle re-materialises every table through the catalog, so it applies deletes, collapses superseded rows, and includes anything still inlined — a copy of the data path would do none of those. It reads without writing, and its manifest is only written once every table's re-read row count matches. Include history to copy the metadata catalog too, which is what keeps time travel working after you leave.
